Ik heb gewerkt aan mijn eigen variant van bongo cat. 
Voor dit project heb ik onderzoek gedaan naar de python library TKinter en heb daarmee een simpel project gemaakt wat ik zelf ook grappig vind om te gebruiken.

Het programma werkt heel simple als je klikt dan verandert het plaatje en komt er een klik bij de counter.
Ik heb voor de leuk van het project ook nog een paar andere dingetjes erbij gevoegd zoals,
1. een klok.
2. een manier om het programma te sluiten
3. hij blijft boven alles staan als je hem open hebt dus je ziet hem altijd in je scherm bewegen.
